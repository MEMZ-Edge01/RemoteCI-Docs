# 快速开始

RemoteCI 有三项运行组件：ClassIsland 插件、RemoteCI 服务端和 Wear OS 客户端。只在同一局域网内使用时可以直连插件；需要跨网络、账号管理或集中控制时，应部署服务端。

::: danger 当前不能作为正式验收教程
2026-08-11 的开发中源码存在已确认的三端协议不一致，云端配对、手表登录和远程命令尚不能据此宣称端到端可用。下面步骤用于说明目标流程；请先阅读[开发状态](./status.md)，并等待对应版本完成三端验证。
:::

## 准备工作

| 组件 | 要求 |
| --- | --- |
| 教室电脑 | 已安装并可正常运行的 ClassIsland 2.x |
| 手表 | Wear OS 3 或更高版本 |
| 服务端 | 支持 Docker 的 NAS 或 Linux 服务器，建议有域名和 HTTPS |
| 网络 | 局域网直连默认使用 TCP 8765；服务端默认使用 TCP 8080 |

目前项目处于早期阶段。如果 Releases 页面尚无可用安装包，需要从 RemoteCI 源码自行构建插件和手表应用。

## 一、部署服务端

按照[服务端部署](../server/deployment.md)完成 Docker 部署。首次启动时，服务端会创建管理员账号和一次性插件配对码。

请先查看容器日志并妥善保存：

~~~powershell
docker logs remoteci
~~~

如果部署时没有显式设置初始密码和配对码，日志中会显示自动生成的值。首次登录后应立即修改管理员密码。

## 二、连接 ClassIsland 插件

1. 在 ClassIsland 中安装 RemoteCI 插件。
2. 打开“设置”中的“RemoteCI 设置”。
3. 局域网直连需要启用局域网服务，并确认端口，默认是 <code>8765</code>。
4. 云端中转需要启用云端连接，填写服务端的完整地址。
5. 填写服务端生成的一次性插件配对码。
6. 保存设置并重启 ClassIsland。

::: tip 地址写法
本机测试可以填写 <code>http://localhost:8080</code>。手表真机跨网络访问时，应填写带 HTTPS 的公网地址，例如 <code>https://remoteci.example.com</code>。
:::

## 三、创建手表账号

登录服务端管理界面，为手表使用者创建账号并分配权限。建议只授予实际需要的权限：

- 查看状态：读取当前课程和连接状态。
- 查看课表：读取七日课表。
- 管理课表：执行换课、替换课程等操作。
- 发送通知：向 ClassIsland 发送通知。
- 管理用户：创建、修改和停用其他账号。

## 四、连接 Wear OS 客户端

1. 打开手表端设置。
2. 填写服务端创建的用户名；密码只用于本次登录，不写入手表设置。
3. 若启用局域网连接，填写运行 ClassIsland 插件的电脑 IP 和端口。
4. 若启用云端连接，填写服务端地址。
5. 保存并连接。

手表会优先尝试局域网直连，失败后再尝试云端连接。Android 模拟器访问宿主机时可使用 <code>10.0.2.2</code>；真机不能使用这个地址。

## 五、确认连接

- 手表首页显示当前课程或“暂无课程”，而不是连接错误。
- 服务端概览显示插件在线和手表在线。
- ClassIsland 切换课程状态后，手表能收到更新。
- 有操作权限的账号可以提交一次非破坏性的测试操作，并看到返回结果。

如果其中一步失败，请查看[连接方式](./connection.md)和[故障排查](./troubleshooting.md)。
