# 快速开始

RemoteCI 有三项运行组件：ClassIsland 插件、RemoteCI 服务端和 Wear OS 客户端。只在同一局域网内使用时可以直连插件；需要跨网络、账号管理或集中控制时，应部署服务端。

## 准备工作

| 组件 | 要求 |
| --- | --- |
| 教室电脑 | 已安装并可正常运行的 ClassIsland 2.x |
| 手表 | Wear OS 3 或更高版本，RemoteCI 手表应用 0.2.0 |
| 服务端 | 支持 Docker 的 NAS 或 Linux 服务器，建议有域名和 HTTPS |
| 网络 | 局域网直连默认使用 TCP 8765；服务端默认使用 TCP 8080 |

发布包从 GitHub Releases 获取：服务端提供 linux-x64 与 win-x64 压缩包，插件提供 CIPX，手表提供 APK。如果 Releases 尚无可用版本，需要从 RemoteCI 源码自行构建，见[文档同步规则](../development/docs-maintenance.md)。

## 一、部署服务端

按照[服务端部署](../server/deployment.md)使用仓库自带的 <code>compose.yaml</code> 完成部署。首次启动时，服务端会创建管理员账号和一次性插件配对码。

请先查看容器日志并妥善保存：

~~~powershell
docker logs remoteci
~~~

如果部署时没有显式设置初始密码和配对码，日志中会显示自动生成的值。首次登录后应立即在“个人账号”页面修改管理员密码。

## 二、连接 ClassIsland 插件

1. 在 ClassIsland 中安装 RemoteCI 插件（0.2.0）。
2. 打开“设置”中的“RemoteCI 设置”。
3. 局域网直连需要启用局域网服务，并确认端口，默认是 <code>8765</code>。
4. 云端中转需要启用云端连接，填写服务端的完整地址。
5. 登录服务端 WebUI，在概览页点击“生成插件配对码”，把显示的一次性配对码填入插件设置。
6. 保存设置并重启 ClassIsland。

配对码在使用前持续有效，成功配对后立即作废；插件换到长期凭据后会清空本地配对码。

::: tip 地址写法
本机测试可以填写 <code>http://localhost:8080</code>。手表真机跨网络访问时，应填写带 HTTPS 的公网地址，例如 <code>https://remoteci.example.com</code>。
:::

## 三、创建手表账号

登录服务端 WebUI 的“人员权限”页面，为手表使用者创建账号：

- ID：登录唯一标识，3-32 位字母、数字、点、下划线或短横线。
- 用户名：显示名，1-40 个字符，会出现在通知的“由用户名发送：”前缀中。
- 初始密码：8-128 位；密码只用于登录，不会下发到插件或写入手表。
- 角色：普通用户或管理员；管理员固定拥有全部权限。
- 附加权限：WebUI、人员管理、发送与清除通知、换课、主界面与电源控制。

建议只授予实际需要的权限。普通用户默认只能查看当前课程，需要操作时再按需勾选。

## 四、连接 Wear OS 客户端

1. 打开手表端“设置 → 连接”。
2. 填写服务端创建的 ID（不是显示名）；密码只用于本次登录，不写入手表设置。
3. 若启用局域网连接，填写运行 ClassIsland 插件的电脑 IP 和端口。
4. 若启用云端连接，填写服务端地址。
5. 保存并登录。

登录成功后，30 天设备会话由 Android Keystore 加密保存在手表上，后续可以优先局域网直连、失败再自动续登云端。Android 模拟器访问宿主机时可使用 <code>10.0.2.2</code>；真机不能使用这个地址。

## 五、确认连接

- 手表首页显示当前课程或“暂无课程”，而不是连接错误。
- 服务端概览显示插件在线和在线手表数。
- ClassIsland 切换课程状态后，手表能收到更新。
- 有权限的账号可以提交一次非破坏性操作（例如发送通知）并看到真实回执。

如果其中一步失败，请查看[连接方式](./connection.md)和[故障排查](./troubleshooting.md)。
