# 故障排查

## 手表一直显示连接失败

1. 确认用户名和密码正确，账号未被停用。
2. 确认服务端健康检查可以访问。
3. 真机不要使用 <code>10.0.2.2</code> 或 <code>localhost</code>。
4. 检查反向代理是否允许 WebSocket 升级。
5. 检查证书是否受手表信任。

## 局域网无法连接

1. 确认 ClassIsland 已重启并加载插件。
2. 确认插件中已启用局域网服务，端口与手表填写一致。
3. 从同一局域网的另一台设备测试电脑 IP 是否可达。
4. 检查 Windows 防火墙和 Wi-Fi 客户端隔离。

## 能查看状态但不能换课

- 确认账号拥有“管理课表”权限。
- 确认插件在线。
- 重新打开课表，避免使用已经过期的课表版本提交操作。
- 查看操作结果中的错误信息；超时通常表示服务端未在规定时间内收到插件响应。

## 首次启动找不到密码

如果没有配置 <code>REMOTECI_ADMIN_PASSWORD</code>，初始密码只会写入首次启动日志。先检查容器的完整日志。

若数据库已经初始化，修改环境变量不会重置现有管理员密码。不要删除数据库来“重置密码”，这会同时删除账号和设备会话。

## 健康检查

~~~powershell
Invoke-RestMethod https://remoteci.example.com/api/health
~~~

正常响应包含 <code>status: ok</code> 和协议版本。健康检查成功只说明 Web 服务已运行，不代表插件和手表已经在线。
