# 功能说明

## 课程状态

插件从 ClassIsland 收集当前课表状态，并向已连接的手表和服务端推送：

- 当前课程与下一节课程。
- 当前时间段和下一时间段。
- 课程开始或结束倒计时。
- 当前课表名称、周次和单双周信息。
- 状态生成时间，用于判断数据是否过期。

## 七日课表

服务端保存插件最近一次推送的七日课表，手表可以按日期浏览课程。插件离线后仍可查看最后一次同步的数据，但页面上的更新时间可能已经过期。

## 手表端操作

当前协议包含以下远程操作：

- 调整单双周。
- 交换两节课程。
- 用指定科目替换课程。
- 向 ClassIsland 发送通知。

操作会由服务端检查账号权限，再交给在线插件执行。插件离线、权限不足、课表已经变化或等待超时时，操作会失败，不会静默排队。

::: warning 操作前确认
换课和替换课程会改变 ClassIsland 当前使用的课表状态。正式使用前应先在测试课表中确认行为。
:::

## 通知

插件可以把上课、下课等事件同步给手表，手表通过系统通知和振动提醒。拥有“发送通知”权限的账号也可以从服务端或手表提交自定义通知。

## 账号和权限

服务端使用独立账号登录，并为不同使用者分配权限。设备会话可以被撤销；修改密码后，原有设备登录会失效。

管理员应遵循最小权限原则，不要给普通查看账号授予“管理用户”或“管理课表”权限。

## 当前未包含

以下内容属于后续方向，不应当作现有功能使用：

- Wear OS Tiles 小组件。
- watchOS 客户端。
- 针对特定国产手表系统的专用适配。
- 面向公网的托管服务。
