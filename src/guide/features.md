# 功能说明

## 课程状态

插件从 ClassIsland 收集当前课表状态，每秒推送给手表和服务端：

- 当前课程与下一节课程。
- 当前时间段和下一时间段。
- 上课或课间剩余倒计时。
- 课表方案名称、是否启用和是否已加载。
- 状态生成时间，用于判断数据是否过期。
- 主界面显隐状态、睡眠/休眠可用性，以及音量状态（是否可控、百分比、静音）。

当前时间段使用插件本地时间，并随快照携带插件时区偏移（`timeZoneOffsetMinutes`）。手表以快照的 UTC 生成时间加该偏移推算插件本地当前时间，再计算课程进度环，因此即使手表与电脑时区设置不一致，上课/课间进度环也能正常显示。

## 七日课表

服务端保存插件最近一次推送的七日课表，包含每天日期、修订号、课程列表和科目清单，手表可以按日期浏览。插件离线后仍可查看最后一次同步的数据，但更新时间可能已经过期。

## 账号与权限

服务端使用独立账号登录，有效权限是位掩码：

| 值 | 权限 |
| --- | --- |
| 1 | 查看当前课程（普通用户固定拥有） |
| 2 | WebUI 访问 |
| 4 | 人员管理 |
| 8 | 发送与清除通知 |
| 16 | 换课 |
| 32 | 主界面与电源控制 |

管理员的有效权限固定为 63（全部权限）。普通用户默认只含值 1，其余权限由管理员在“人员权限”页面分配。设备会话可以被撤销；修改密码后，原有设备登录会失效。

## 手表端操作

控制页中的操作由服务端检查账号权限后交给在线插件执行，并返回真实回执。插件离线、权限不足、课表已变化或等待超时时，操作会失败，不会静默排队。

- 首页：旋转表冠或表圈可在课程状态页与菜单页之间切换，一格翻一页；菜单页直接展示功能选项，无需滚动。
- 换课：选择日期，交换两节课或用指定科目替换；提交时携带课表修订号，防止覆盖别人刚完成的修改。
- 快速换课：主界面点击当前课程按钮，直接进入换课页并把当前这节课预选为“原课”，无需先选日期；返回键直接回主页。
- 发送通知：向 ClassIsland 发送自定义通知，成功后广播给手表。
- “老师来了”：快捷提醒，显示“老师来了”并只开启提醒强调特效，1 秒后自动清除。
- 清除提醒：清除 ClassIsland 当前提醒。
- 主界面：显示或隐藏 ClassIsland 主界面。
- 电源：关机、重启、睡眠或休眠；休眠入口只在插件报告可用时显示。
- 音量：调整 Windows 默认播放设备 0-100 的主音量或切换静音，页面以插件上报的真实状态刷新。
- 扩展：其他 ClassIsland 插件注册的扩展功能显示在控制页底部，按参数表单填写后执行。

::: warning 操作前确认
换课、替换课程、电源与音量会改变教室电脑的真实状态。正式使用前应先在测试课表中确认行为。
:::

## 通知

插件可以把七类事件同步给手表，手表端可以逐类开关并触发系统通知和振动：上课、课间、放学、课表变更、自定义消息、ClassIsland 自动化“显示提醒”、第三方 ClassIsland 插件通知。

自定义通知的标题与正文均可留空：标题留空时显示默认标题“RemoteCI 通知”，正文留空时显示原标题。通知由插件执行时添加“由用户名发送：”前缀（可由服务端全局设置关闭），发送者名称取账号的用户名（显示名），客户端无法覆盖。通知请求还可以分别控制提醒强调特效、提醒音效和语音朗读；省略时均为关闭。

## 更新

- 服务端：管理员在“个人账号 → 系统更新”检查 GitHub 最新 release；Windows、Linux 与 Docker 会按各自安全流程替换文件并自动重启。
- 手表：必须先连接 WebUI，只能检查并安装不高于该 WebUI 版本的 APK；安装确认回调使用 Android PackageInstaller 的可变显式 PendingIntent。
- 插件：升级由 ClassIsland 插件市场统一管理。
- 飞牛 fnOS：检查和升级由 fnOS 应用商店统一管理，WebUI 不提供下载按钮。

## 外观主题

手表在“设置 → 外观”中可以切换整套 Material Design 3 配色方案，选择后立即生效并保存在本机，重启不会丢失。内置方案：

| 配色 | 说明 |
| --- | --- |
| 淡紫 | 默认方案，对齐现有 Figma 设计与 M3 淡紫容器色 |
| 经典紫 | M3 默认紫色（primary #6750A4）系列 |
| 蓝色 | M3 blue 官方色板 |
| 绿色 | M3 green 官方色板 |
| 橙色 | M3 orange 官方色板 |
| 粉色 | M3 pink 官方色板 |

配色切换只影响手表应用自身的界面（首页、课表、设置等），不会改变通知内容或协议行为。

## 当前未包含

以下内容属于后续方向，不应当作现有功能使用：

- Wear OS Tiles 小组件。
- watchOS 客户端。
- 针对特定国产手表系统的专用适配。
- 面向公网的托管服务。
- 真实写入 ClassIsland 的“切换单双周”功能（已移除）。
